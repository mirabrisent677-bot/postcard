# کارت پستال دیجیتال - نسخه نهایی

## ویژگی
با کلیک روی «دریافت پیام»، عکس داخل سایت و پیام با هم به صورت نرم و متحرک نمایش داده می‌شوند.

## اجرا
1. Python را نصب کنید.
2. داخل پوشه پروژه ترمینال باز کنید.
3. اجرا کنید:
   pip install flask
4. سپس:
   python app.py
5. مرورگر:
   http://127.0.0.1:5000

## تغییر پیام
فایل app.py را باز کنید و مقدار MESSAGE را تغییر دهید.

## تغییر عکس
عکس فعلی در این مسیر قرار دارد:
static/images/postcard.png

اگر خواستی عکس دیگری بگذاری، عکس جدید را با همین نام جایگزین کن.
